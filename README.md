# Çaydanlık Kaynama Sesi Orkestratörü

**Resmiyet derecesi:** aşırı  
**Bilimsel değeri:** tartışmalı  
**Çay kalitesi:** kodun işine bakmaz

Bu depo, sıradan bir mutfak olayını — çaydanlığın kaynamasını — ulusal bir tören gibi yönetmek için yazılmıştır. Yazılım buhar üretmez. Yazılım **karar** üretir.

## Neden var?

Çünkü bir çaydanlık kaynarken çıkardığı ses, evrenin en az belgelenmiş senfonisidir. Biz belgelledik. Sonra belgelere mühür bastık. Sonra mührü de belgelledik.

## Kurulum

```bash
python3 orkestrator.py
```

Daha uzun bir tören için dakika verin:

```bash
python3 orkestrator.py 5
```

## Çıktı neye benzer?

Sıcaklık yükselir. Sesler çıkar. Bir yerde 100C'ye varılır. Komisyon memnun kalır. Siz çay içersiniz. Yazılım alkışlamaz; alkış bütçesi yoktur.

## Sorumluluk reddi

- Gerçek ocağı açmaz.
- Gerçek çay demlemez.
- Gerçek komşuyu çağırmaz.
- Yalnızca terminalde resmiyet biriktirir.
